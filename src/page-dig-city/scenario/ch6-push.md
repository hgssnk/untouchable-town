# 第6章 置く

## 場面1：部屋

- 場所：主人公の部屋（夜）。雨上がり
- できること：Aで文を進めるだけ
- 文：
```
  六日目の夜。

  決めるのは、/もうやめる。

  誘うのも、/やめる。

  来たくなる場所を、/置くだけだ。

  ……濡れない場所。
```
- 次：場面2へ

## 場面2：下見

- 場所：公園の端（夜）。高架が公園の上をかすめていて、その下だけ地面が乾いている
- できること：十字キーで歩く。Aで調べる
- 調べられるもの：
  - 高架の下の乾いた地面
```
    ここだけ、/雨が届かない。

    公園と高架下の、/ちょうど境目。

    傘も、/構造だ。
```
  - 街灯
```
    ケンと会った灯り。/今夜は、誰もいない。
```
- 次：乾いた地面でAを押したら、場面3へ

## 場面3：置く夜

- 場所：公園の端（夜）
- できること：一晩に一つだけ、下から選んで置く。置いたら、ループを鳴らして夜を過ごす。これを三晩くり返す（四つのうち三つしか置けない）
- 補足：マイクスタンドだけは、最初の夜に必ず置く（選択肢には出ない）。誰も使わないまま、毎晩そこに立っている
- 置けるもの：
  - シート：高架の端から張る屋根。雨に強くなる
  - 灯り：小さなランタン。人が来やすくなる
  - ベンチ：木箱を並べた椅子。来た人が長くいる
  - レコード箱：自分の盤を並べた箱。来た人が掘り始める
- 文（マイクスタンドを置いたとき）：
```
  マイクスタンドを、/一本立てる。

  誰のためでもない。/ただ、置いておく。

  歌われていない歌は、/歌われるまで、

  歌かどうかも/決まらない。
```
- 文（毎晩、鳴らし終えたとき）：
```
  今夜も、/鳴らしただけ。

  誘わない。/決めない。/……待つ。
```
- 補足：二晩目の終わりに場面4、三晩目の終わりに場面5が起こる
- 次：三晩目が終わったら、場面6へ

## 場面4：ミオ

- 場所：公園の端（夜）。ミオが傘を持って立っている
- できること：Aで文を進める
- 補足：第5章でミオが傘を置いていった場合は、文Aが出る。そうでない場合は文B
- 文A：
```
  あの夜の傘。/返そうとして、止められた。

  ミオ：……持ってて。/また降るかもしれない。

  ミオ：今日は、/何も言わないんだ。

  うん。

  ミオ：……じゃあ、/弾こうかな。
```
- 文B：
```
  ミオ：毎晩、/ここで鳴らしてるって。

  ミオ：今日は、/何も言わないんだ。

  うん。

  ミオ：……じゃあ、/弾こうかな。
```
- 次：場面3に戻る

## 場面5：ケン

- 場所：公園の端（夜）。ケンが、知らない二人を連れてくる
- できること：Aで文を進める
- 文：
```
  ケン：よっ。/連れてきた。

  ケン：誘われたから、/じゃないよ。

  ケン：ここ、/なんか居やすいから。
```
- 次：場面3に戻る

## 場面6：土曜

- 場所：公園の端（夜）。置いたものが並んでいる。チラシは貼っていない
- できること：十字キーで歩く。誰かの前でAを押しても、主人公は何も言わない
- 補足：来る人の数は、置いたもので変わる（灯りで増える、ベンチで残る、レコード箱で掘る人が出る）。途中で必ず雨が降る。シートを置いていれば音は止まらない。置いていなければ、人が高架の下に詰め寄って、それでも鳴り続ける
- 文（始まったとき）：
```
  誰も呼んでいない。

  でも、/人がいる。
```
- 文（誰かの前でA）：
```
  ……言わなくていい。
```
- 文（レコード箱を置いた場合、箱の前でA）：
```
  知らない誰かが、/箱をめくっている。

  手が、/一枚のところで止まった。
```
- 文（雨が降り出したとき）：
```
  ぽつ。

  ……降った。

  でも、/音は止まらなかった。

  雨が、シートを叩く。/それもリズムになる。
```
- 次：場面7へ

## 場面7：マイク

- 場所：公園の端（夜、雨）
- できること：Aで文を進めるだけ
- 補足：フードの男が雨の中から歩いてきて、誰にも何も言わず、マイクスタンドの前に立つ
- 文：
```
  ロク：止まった針を/また落とす

  ロク：雨の中でも/鳴りやまない

  ロク：決めたのは/場所だけだ

  ロク：……あとは、/勝手に鳴る。
```
- 補足：歓声が上がる。ミオのベース、ケンのスクラッチ、雨、電車が重なる
- 次：場面8へ

## 場面8：終わったあと

- 場所：公園の端（深夜）。人がまばらになっている
- できること：Aで文を進めるだけ
- 文：
```
  ロク：……何も、/言わなかったな。

  言わなくても、/来たから。

  ロク：三年かかった。/俺は。

  ロク：お前は、/一週間だ。

  ロク：……悪くない。
```
- 次：部屋に戻ったら、場面9へ

## 場面9：部屋

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。机でAを押すとループを鳴らせる。布団の前でAを押すと寝る
- 文（部屋に入ったとき）：
```
  置いただけ。

  それで、/全部が鳴った。
```
- 文（机でA）：
```
  ループを鳴らす。

  もう、/頭の中だけの音じゃない。
```
- 文（布団の前でA）：
```
  疲れた。/でも、悪くない。
```
- 次：暗転して「第6章 置く おわり」。第7章へ。街に「公園の歓声」の音の層が加わる（レコード箱を置いた場合は「盤をめくる人の音」も加わる）
