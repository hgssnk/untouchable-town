# 第4章 集める

## 場面1：部屋

- 場所：主人公の部屋（夜）
- できること：Aで文を進めるだけ
- 文：
```
  四日目の夜。

  高架下だけじゃない。/街のあちこちで鳴らす。

  誰かが、/反応するかもしれない。

  夜は短い。/回れるのは、三か所くらいだ。
```
- 次：場面2へ

## 場面2：夜の街を回る

- 場所：街（夜）。画面の隅に時計（22時から始まる）
- できること：十字キーで歩く。鳴らせる場所でAを押すと、ループを鳴らす。1回鳴らすと1時間進む。25時になると、その夜は終わり
- 補足：出会えるかどうかは確率。場所・時間・置き方で確率が上がる。外れたときの文が、次のヒントになる
- 鳴らせる場所：
  - 喫茶店の裏口：23時以降だと、ミオに会える確率が高い
  - 公園：ベンチ・街灯の下の2か所。街灯の下だと、ケンに会える確率が高い
  - 高架下：ロクがいることがある（仲間にはならない）
  - コインランドリー：誰も来ない
- 文（喫茶店の裏口、23時より前）：
```
  まだ営業中だ。/店の音にかき消される。
```
- 文（喫茶店の裏口、23時以降で外れ）：
```
  裏口は静かだ。

  ……今夜は、/誰も出てこない。

  来ない確率も、/確率のうちだ。
```
- 文（公園のベンチ）：
```
  音が、/夜の広さに負けている。

  ……広いものには、/たいてい負ける。

  もう少し、/明るい所で鳴らすか。
```
- 文（公園の街灯の下で外れ）：
```
  光の中で、/音だけが回っている。

  ……今夜は、/誰も来ない。
```
- 文（コインランドリー）：
```
  乾燥機が、/リズムを刻んでいる。

  回転数は、/たぶん一定。

  ……いい音だ。/でも、誰も来ない。
```
- 次：ミオかケンに会えたら、場面3・場面4へ。25時になったら、場面6へ

## 場面3：ミオ

- 場所：喫茶店の裏口（夜）。エプロン姿の女性がドアを開ける
- できること：Aで文を進める
- 文：
```
  ミオ：……うるさい。

  ミオ：嘘。/そのベースライン、何？

  ベースは、/入ってない。

  ミオ：だから、/足りないって言ってるの。
```
- 補足：ミオが店からベースを持ってきて、ループに合わせて弾く
- 文（弾いたあと）：
```
  低い音が、/床を這う。

  ループが、/急に歩き出した。

  ミオ：店を閉めたあとなら、/いつでも弾ける。
```
- 次：場面2に戻る（時間はそのまま）

## 場面4：ケン

- 場所：公園の街灯の下（夜）。スケボーを抱えた男が近づいてくる
- できること：Aで文を進める
- 文：
```
  ケン：おっ、/それ生の盤？

  ケン：ちょっと、/貸して。
```
- 補足：ケンが盤に手を置き、スクラッチする
- 文（スクラッチのあと）：
```
  キュッ、キュキュッ。

  盤が、/しゃべり出した。

  ケン：夜の公園、/毎日いるから。
```
- 次：場面2に戻る（時間はそのまま）

## 場面5：ロク

- 場所：高架下（夜）。暗がりに、フードの男
- できること：Aで文を進める
- 補足：高架下で鳴らしたとき、ときどき起こる。ミオとケンに会ったあとだと、文が変わる
- 文（まだ誰にも会っていないとき）：
```
  ロク：……今夜も、/一人か。
```
- 文（ミオかケンに会ったあと）：
```
  ロク：……増えたな。

  ロク：人が増えると、/音は良くも悪くもなる。

  ロク：覚えておけ。
```
- 次：場面2に戻る

## 場面6：部屋（まだ集まっていない夜）

- 場所：主人公の部屋（深夜）
- できること：布団の前でAを押すと寝る
- 補足：ミオとケンの両方に会えていない夜は、ここで寝る。章は終わらず、次の夜に場面2から続く
- 文（布団の前でA）：
```
  今夜は、/ここまでか。

  明日も、/鳴らしに行こう。
```
- 次：翌日の夜、場面2へ（時計は22時に戻る）

## 場面7：部屋（二人に会えた夜）

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。机でAを押すとループを鳴らせる。布団の前でAを押すと寝る
- 文（部屋に入ったとき）：
```
  ベースと、/スクラッチ。

  一人だった音に、/人が増えていく。

  もっと人がいれば、/もっと鳴る。

  ……そう思った。
```
- 文（机でA）：
```
  ループを鳴らす。

  頭の中で、/みんなの音が重なる。
```
- 文（布団の前でA）：
```
  誰かの笑い声が、/窓の外から聞こえる。
```
- 次：暗転して「第4章 集める おわり」。第5章へ。街に「ミオのベース」と「ケンのスクラッチ」の音の層が加わる
