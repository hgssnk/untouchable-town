# 第3章 鳴らす

## 場面1：部屋

- 場所：主人公の部屋（夜）。机の上にプレーヤー
- できること：Aで文を進めるだけ
- 文：
```
  三日目の夜。

  盤をかけたまま、/ずっと考えていた。

  このまま鳴らしても、/誰かの曲のままだ。

  切って、並べる。/自分の音にする。
```
- 次：場面2へ

## 場面2：チョップ

- 場所：机の上（音の波形のアップ）
- できること：曲が流れる。キック・スネアが来た瞬間にAで切る。4つ切るとループになる
- 補足：切る位置がずれると、ループがもたつく。何度でもやり直せる
- 文（ずれたとき）：
```
  もたついた。/もう一度。
```
- 文（4つ切れたとき）：
```
  ドン、タン。/ドドン、タン。

  止まらない。/ずっと回っている。

  ……できた。
```
- 次：プレーヤーを持って外に出たら、場面3へ

## 場面3：夜の街

- 場所：街（夜）。主人公はプレーヤーを持っている
- できること：十字キーで歩く。Aで調べる
- 調べられるもの：
  - 自販機
```
    つめたい、も/戻っていた。
```
  - 中古屋（閉まっている）
```
    今日は定休日。/ガラスに、自分が映る。
```
  - 掲示板
```
    三年前のチラシ。/今夜は、素通りした。
```
- 次：高架下に着いたら、場面4へ

## 場面4：高架下

- 場所：高架下（夜）。柱が並ぶ。置ける場所が3か所ある（出口の近く／柱の陰／真ん中）
- できること：十字キーで歩く。置ける場所でAを押すと、プレーヤーを置いて鳴らす
- 補足：真ん中以外では、しばらく鳴らしても何も起きない。場所を変えられる
- 文（着いたとき）：
```
  誰もいない。

  ここなら、/音がよく響きそうだ。
```
- 文（出口の近くで鳴らしたとき）：
```
  音が、/外に逃げていく。

  ……逃げ足だけは、/速い。
```
- 文（柱の陰で鳴らしたとき）：
```
  柱に吸われて、/こもってしまう。
```
- 文（真ん中で鳴らしたとき）：
```
  壁に当たって、/音が返ってくる。

  ここだ。
```
- 次：真ん中で鳴らしたら、場面5へ

## 場面5：電車

- 場所：高架下（夜）
- できること：Aで文を進めるだけ
- 補足：ループが鳴る中、頭上を電車が通る。電車の音がループのリズムに重なる。そのあと、暗がりから声が乗る
- 文：
```
  電車が来た。

  ガタン、ゴトン。/……合っている。

  時刻表は、/偶然までは約束しない。

  暗がりから、/声がした。
```
- 文（声の主がラップする）：
```
  ？？？：止まった針を/また落とす

  ？？？：三年分の/ホコリを払う

  ？？？：……まだ、/鳴るのかよ。
```
- 次：場面6へ

## 場面6：声の主

- 場所：高架下（夜）。フードをかぶった男が、柱にもたれている
- できること：Aで文を進める。途中で選択肢を2回選ぶ
- 文：
```
  男：その盤、/どこで拾った。
```
- 選択肢：「中古屋で」「百円で」（どちらでも同じ文に続く）
- 文（選んだあと）：
```
  男：……百円か。/安くなったもんだ。

  男：昔の、/知り合いの音だ。

  盤の最後の声。/あんたか？

  男：……さあな。

  男：俺はもう、/やってない。

  男：でも、/そのスネアは悪くない。

  男：明日も、/ここで鳴らすのか。
```
- 選択肢：「鳴らす」「分からない」（どちらでも同じ文に続く）
- 文（選んだあと）：
```
  男：……そうか。

  男：名前は、/聞くなよ。

  男：観測すると、/変わる。

  男は、/暗がりに戻っていった。

  名前も、/聞かなかった。
```
- 次：高架下を出たら、場面7へ

## 場面7：帰り道

- 場所：街（深夜）
- できること：十字キーで歩く。Aで調べる
- 調べられるもの：
  - 掲示板（寄らなくても先に進める）
```
    三年前のチラシ。/隅に、小さな文字。

    「MC ロク」

    ……まさかな。
```
- 次：部屋の前に着いたら、場面8へ

## 場面8：部屋

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。机でAを押すとループを鳴らせる。布団の前でAを押すと寝る
- 文（机でA）：
```
  ループを鳴らす。

  あの声が乗らないと、/少しさびしい。
```
- 文（布団の前でA）：
```
  耳に、/まだ残っている。
```
