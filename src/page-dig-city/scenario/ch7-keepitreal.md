# 第7章 手放す

## 場面1：部屋

- 場所：主人公の部屋（夜）
- できること：Aで文を進めるだけ
- 文：
```
  七日目の夜。

  今夜は、/何も予定がない。

  ……少し、/歩くか。
```
- 次：外に出たら、場面2へ

## 場面2：最後の散歩

- 場所：街（夜）。プレーヤーは持っていない
- できること：十字キーで歩く。Aで調べる。どこにも寄らずに帰ってもいい
- 補足：主人公はどこでも何もしない。街の人たちは、主人公がいなくても、それぞれの音を鳴らしている
- 調べられるもの：
  - 中古屋（店主と、箱をめくる知らない誰か）
```
    店主：……またお前か。/今日は掘らないのか。

    今日は、/見てるだけ。

    店主：観測だけか。/……一番安上がりだ。

    店主：……そうか。
```
  - 掲示板
```
    三年前のチラシの横に、/新しいチラシ。

    「公園で、音を鳴らそう」

    知らない字だ。
```
  - 喫茶店の裏口
```
    裏口から、/ベースが漏れている。

    ノックは、/しなかった。
```
  - 公園
```
    街灯の下で、ケンが/誰かに盤を回させている。

    笑い声。/……いい音だ。
```
  - 高架下
```
    ロクが、/誰かに何か教えている。

    こちらに気づいて、/片手だけ上げた。
```
  - コインランドリー
```
    乾燥機が、/今夜もリズムを刻んでいる。
```
- 次：部屋の前に着いたら、場面3へ

## 場面3：部屋

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。布団の前でAを押すと寝る
- 補足：机でAを押しても、盤はかけない
- 文（机でA）：
```
  今夜は、/鳴らさなくていい。

  鳴らさない音も、/そこにある。
```
- 文（布団の前でA）：なし
- 次：暗転しない。場面4へ

## 場面4：眺める

- （前回の内容はそのまま）
- 次：街を一周し、スタッフロールが流れ終わったら、場面5へ

## 場面5：手放す

- 場所：ゲームボーイの外。現実の部屋（夜）
- できること：なし
- 補足：
  - カメラが引いて、ゲームボーイの画面の枠と、それを持つ両手が見える。ここから先は、緑4色ではなく、色のある絵になる
  - 手が、ゲームボーイを机に置く。画面の中では街が鳴り続けている（音は小さく、机の上から聞こえる）
  - 部屋のドアが開き、外の夜が見える。遠くに中古屋の灯り
- 文：
```
  ……行ってみるか。
```
- 次：その景色のまま止まる。机の上のゲームボーイは、ずっと鳴り続ける。次に起動すると、タイトル画面に「眺める」が追加されている
