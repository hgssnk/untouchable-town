# 第2章 直す

## 場面1：部屋

- 場所：主人公の部屋（夜）。机の上にラベルのない盤
- できること：Aで文を進めるだけ
- 文：
```
  次の夜。

  ラベルのない盤は、/まだ黙っている。

  鳴らしたい。/でも、鳴らす機械がない。

  ……あの店に、/何かあるかもしれない。
```
- 次：夜の街を歩く

## 場面2：夜の街

- 場所：街（夜）。第1章と同じ地図
- できること：十字キーで歩く。Aで調べる
- 調べられるもの：
  - 自販機
```
    あたたかい、が/補充されていた。
```
  - 掲示板
```
    三年前のチラシ。/まだ、剥がされていない。
```
  - 高架下（今夜は何も聞こえない）
```
    今夜は、/何も聞こえない。

    電車の音だけが、/上を通りすぎた。
```
- 次：中古屋の入り口に着いたら、場面3へ

## 場面3：店内

- 場所：中古屋の中
- できること：十字キーで歩く。Aで話す・調べる
- 調べられるもの：
  - 店主
```
    店主：また来たか。

    店主：……鳴らす物を/探しに来た顔だな。

    店主：ジャンクなら、/ある。

    店主：動くかは知らん。/直せるなら、安い。
```
  - 奥の箱
```
    今日は、/掘りに来たんじゃない。
```
- 次：店主と話し終えたら、場面4へ

## 場面4：ジャンク

- 場所：レジの前。カウンターに、古いポータブルプレーヤー
- できること：Aで文を進める
- 文：
```
  トランク型の/プレーヤー。

  スピーカーが/ふたに付いている。

  電源を入れても、/何も回らない。

  店主：五百円だ。

  店主：袋に入れておく。/持っていけ。
```
- 次：店を出て部屋に戻ったら、場面5へ

## 場面5：袋の中

- 場所：主人公の部屋（夜）。机の上にプレーヤーと袋
- できること：Aで文を進める
- 文：
```
  袋の底に、/小さな包みがある。

  替えのベルトと、/新しい針。

  メモが一枚。

  「順番が逆なやつへ」
```
- 次：場面6へ

## 場面6：修理

- 場所：机の上（プレーヤーのアップ）
- できること：下の4つの作業を、好きな順で行う。全部終わると完了
- 補足：作業ごとに小さな操作がある
  - 裏ぶたのネジ：4本。Aを押し続けて1本ずつ回す
  - ベルト：伸びたベルトを外し、新しいベルトを十字キーで回るようにかける
  - 配線：外れた線を、同じ色の端子につなぐ
  - 針：古い針を抜き、新しい針をまっすぐ差す
- 文（ネジを外したとき）：
```
  中は、/思ったより静かだった。

  ネジが一本、余った。

  ……余ったものは、/たいてい必要だった。
```
- 文（古いベルトを外したとき）：
```
  伸びきっている。/これじゃ回らない。
```
- 文（配線をつないだとき）：
```
  赤は赤へ。/それだけのことだ。
```
- 文（古い針を抜いたとき）：
```
  先が、/丸くなっている。

  たくさん、/鳴らしてきたんだろう。
```
- 文（全部終わったとき）：
```
  ふたを閉じる。

  電源を入れた。

  ……回った。
```
- 次：場面7へ

## 場面7：針を落とす

- 場所：机の上（盤のアップ）
- できること：アームを十字キーで動かし、盤の縁の少し内側でAを押して針を落とす
- 補足：外側すぎると失敗、内側すぎると途中から始まる（どちらもやり直し）
- 文（外側すぎたとき）：
```
  縁で、/針が滑った。

  境界は、/いつも危ない。
```
- 文（内側すぎたとき）：
```
  途中から鳴った。/最初から聴きたい。
```
- 次：うまく落ちたら、場面8へ

## 場面8：初めての音

- 場所：主人公の部屋（夜）
- できること：Aで文を進めるだけ
- 補足：ここで実際に音が鳴る。ノイズのあとに、遅いテンポのドラム
- 文：
```
  パチ、パチ。

  ……ドラムだ。

  乾いたスネア。/遅いテンポ。

  ネタになる。/そう思った。

  曲の終わり。/誰かの声が、一言。

  ……どこかで、/聞いた声だ。
```
- 次：場面9へ

## 場面9：部屋

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。机でAを押すともう一度鳴らせる。布団の前でAを押すと寝る
- 文（机でA）：
```
  もう一度、/針を落とす。

  何度聴いても、/最後の声が気になる。
```
- 文（布団の前でA）：
```
  このプレーヤーなら、/外にも持っていける。

  明日、外で/鳴らしてみるか。
```
- 次：暗転して「第2章 直す おわり」。第3章へ
