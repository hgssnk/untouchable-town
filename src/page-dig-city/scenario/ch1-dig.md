# 第1章 掘る

## 書き方

場面ごとに `##` で区切る。分かる項目だけ書けばよい。足りない部分は、実装するときに聞く。

- **場所**：どこか
- **できること**：この場面でプレイヤーが操作できること
- **文**：画面に出る文。1画面は2行まで、1行12文字くらいまで。`/` で改行、空行で画面を切る
- **話す人**：文の行頭に `店主：` のように書く。名前は文字数に数えない。書かなければ地の文
- **調べられるもの**：歩ける場面で、Aを押すと文が出るもの
- **次**：どうなったら次の場面に進むか

---

## 場面1：部屋

- 場所：主人公の部屋（夜）
- できること：Aで文を進めるだけ
- 文：
```
  夜。

  誰ともつながらない部屋で/ビートだけを作っている。

  この街に、仲間はいない。/まだ。

  窓の外に、/中古屋の灯りが見えた。

  ……行ってみるか。
```
- 次：夜の街を歩く

## 場面2：夜の街

- 場所：街（夜）。中古屋が左上、高架が右端、真ん中に掲示板
- できること：十字キーで歩く。Aで調べる
- 調べられるもの：
  - 自販機
```
    つめたい、しか/残っていない。
```
  - 掲示板
```
    色あせたチラシ。/「公園で、音を鳴らそう」

    日付は、/三年前だ。
```
  - 高架下（近づくと、かすかに声とリズムが聞こえる）
```
    誰かの声が、/リズムに乗っている。

    近づくと、/音はもう消えていた。
```
- 次：中古屋の入り口に着いたら、場面3へ

## 場面3：中古屋の前

- 場所：中古屋「ハリオト商店」の入り口
- できること：Aで文を進める
- 文：
```
  古い看板。/「買取・販売 ハリオト商店」

  閉店まで、/あと三十分。
```
- 次：入り口でAを押したら、場面4へ

## 場面4：店内

- 場所：中古屋の中。手前に店主、奥にレコードの箱
- できること：十字キーで歩く。Aで話す・調べる
- 調べられるもの：
  - 店主
```
    店主：……いらっしゃい。

    店主：レコードなら、/奥の箱だ。

    店主：全部百円。/当たりは、自分で探せ。
```
  - 棚のラジカセ
```
    値札に「ジャンク」。/……今日はやめておく。
```
- 次：奥の箱の前でAを押したら、場面5へ

## 場面5：ディグ

- 場所：レコードの箱（アップの画面）
- できること：←→で1枚ずつめくる。Aで手に取る
- 補足：箱の中は30枚ほど。当たりの1枚の位置は毎回ランダム。外れを手に取ると、下の文からランダムに1つ出る
- 文（外れ）：
```
  ジャケットだけ、/やけに派手だ。
```
```
  盤に大きな傷。/これは鳴らない。
```
```
  演歌。/……今日じゃない。
```
```
  同じ盤が、/三枚も入っている。
```
- 文（当たりをめくったとき）：
```
  ……ん？

  手が、止まった。
```
- 次：当たりの1枚を手に取ったら、場面6へ

## 場面6：一枚

- 場所：手元（盤のアップ）
- できること：Aを押し続けてホコリを拭く。ゲージが満ちたら終わり
- 文（拭く前）：
```
  ラベルのない盤。/ジャケットもない。

  ホコリで、/溝が見えない。
```
- 文（拭き終わったあと）：
```
  溝が、光った。

  ……これだ。
```
- 次：場面7へ

## 場面7：店主の話

- 場所：レジの前
- できること：Aで文を進める
- 文：
```
  店主：それを選んだか。

  店主：中身は知らん。/誰も聴いてない。

  店主：聴かなくても、/分かることはある。

  店主：溝の深さと、/盤の重さ。

  店主：外から見えるのは、/構造だけだ。

  店主：昔、そういう/研究をしていた。

  店主：……ブラックホールのな。

  ……。
```
- 次：場面8へ

## 場面8：会計

- 場所：レジの前
- できること：Aで文を進める。途中で選択肢を1つ選ぶ
- 文：
```
  店主：百円だ。

  店主：プレーヤーは/持ってるのか？
```
- 選択肢：「持ってない」「これから探す」（どちらでも同じ文に続く）
- 文（選んだあと）：
```
  店主：順番が逆だな。

  いや。/これでいい。

  先に見つける。/鳴らしたいものを。

  店主：……変わったやつだ。

  店主：また来い。
```
- 次：店を出たら、場面9へ

## 場面9：帰り道

- 場所：街（夜が深くなっている）。来た道を戻る
- できること：十字キーで歩く
- 補足：高架下に近づくと、場面2と同じ声が聞こえる。一定の距離まで近づくと止まる
- 文（高架下に近づいたとき）：
```
  また、あの声だ。

  ……消えた。

  今は、まだ/会えないらしい。
```
- 次：部屋の前に着いたら、場面10へ

## 場面10：部屋

- 場所：主人公の部屋（深夜）。机と布団がある
- できること：十字キーで歩く。布団の前でAを押すと寝る
- 文（部屋に入ったとき）：
```
  ラベルのない盤を/机に置いた。

  鳴らす機械は、/まだない。

  でも、/鳴らしたい音はある。

  順番は、/合っている。
```
- 文（布団の前でA）：
```
  ……一旦、寝るか。
```
- 次：暗転して「第1章 掘る おわり」。第2章へ
