# 第5章 崩れる

## 場面1：部屋

- 場所：主人公の部屋（夜）
- できること：Aで文を進める。途中でチラシの言葉を選ぶ
- 文：
```
  五日目の夜。

  ベースがいる。/スクラッチもいる。

  なら、/人を集めればいい。

  公園で、/パーティをやろう。

  日付は、/今週の土曜。
```
- 補足：チラシに書く言葉を選ぶ。選択肢は「公園で、音を鳴らそう」だけ
- 文（選んだあと）：
```
  ……どこかで、/見た言葉だ。

  まあ、いい。
```
- 次：チラシを持って外に出たら、場面2へ

## 場面2：チラシを貼る

- 場所：街（夜）
- できること：十字キーで歩く。掲示板でAを押すとチラシを貼る。通行人に話しかけるとチラシを渡そうとする
- 補足：掲示板では「古いチラシの上に貼る」「隣に貼る」を選べる。どちらでも先に進める
- 文（古いチラシの上に貼ったとき）：
```
  三年前の紙が、/見えなくなった。
```
- 文（隣に貼ったとき）：
```
  同じ言葉が、/二枚並んだ。
```
- 文（通行人に話しかけたとき、ランダムに1つ）：
```
  目を合わせずに、/通りすぎていった。
```
```
  通行人：……あ、/はい。

  受け取って、/すぐポケットにしまった。
```
- 次：掲示板に貼ったら、場面3へ

## 場面3：練習

- 場所：公園の街灯の下（夜）。ミオとケンがいる
- できること：このシーンだけ、画面下に「指示」が出る。「もっと大きく」「テンポを上げて」「今、スクラッチ」「ここで止めて」から選ぶと、二人がその通りに動く。「何も言わない」も選べる
- 補足：指示するたびに、二人の音は言われた通りに変わる。でも、指示の回数が増えるほど二人の返事が短くなる（回数は画面に出さない）
- 文（指示1回目のあと）：
```
  ミオ：……分かった。

  ケン：はいよ。
```
- 文（指示3回目以降のあと）：
```
  ミオ：それ、/あなたの音？

  ケン：なんか、/楽しくなくない？
```
- 文（「何も言わない」を選んだとき）：
```
  言いかけて、/やめた。

  ……でも、/土曜まで時間がない。
```
- 次：一曲終わったら、場面4へ

## 場面4：ロクを誘う

- 場所：高架下（夜）
- できること：Aで文を進める。途中で選択肢を選ぶ
- 文：
```
  土曜、/公園でやる。

  出てくれ。/あんたの声が要る。

  ロク：……やめとけ。
```
- 選択肢：「頼む」「あんたが必要なんだ」（どちらでも同じ文に続く）
- 文（選んだあと）：
```
  ロク：……。

  ロク：三年前の俺と、/同じ顔をしてる。

  ロクは、/振り返らずに行った。
```
- 次：暗転して、土曜の夜。場面5へ

## 場面5：当日

- 場所：公園（夜）。空は曇っている。数人が遠巻きに立っている
- できること：場面3と同じ「指示」が出る。プレイヤーが何を選んでも、途中で雨が降り出す
- 補足：雨が降り出したら、プレーヤーの前でAを押し続けて、盤にシャツをかぶせて守る
- 文（始まったとき）：
```
  来たのは、/数人だけ。

  もっと、/盛り上げないと。
```
- 文（雨が降り出したとき）：
```
  ぽつ。

  ……ぽつ、ぽつ。

  盤が、/濡れる。

  天気予報は、/構造までは教えない。
```
- 文（盤を守ったあと）：
```
  顔を上げると、/誰もいなかった。
```
- 文（場面3で指示が2回以下だった場合、続けて）：
```
  街灯の下に、/ミオだけが残っていた。

  ミオ：……風邪ひくよ。

  ミオは、/傘を置いて帰った。
```
- 次：高架下に向かったら、場面6へ

## 場面6：雨の高架下

- 場所：高架下（夜、雨）。ロクがいる
- できること：Aで文を進めるだけ
- 文：
```
  ロク：……降ったな。

  ロク：三年前も、/こうだった。

  ロク：曲も、順番も、/誰がいつ出るかも。

  ロク：全部、/俺が決めてた。

  ロク：そして、/雨が降った。

  ロク：みんな帰って、/戻ってこなかった。

  ロク：あの盤は、/その前に作った一枚だ。

  ロク：最後の声は、/俺だ。

  ロク：……捨てたつもりが、/百円で売られてた。

  ロク：雨は、/止められない。

  ロク：でも、/濡れない場所はある。

  ロク：……それだけだ。
```
- 次：部屋に戻ったら、場面7へ

## 場面7：部屋

- 場所：主人公の部屋（深夜）。窓の外は雨。机と布団がある
- できること：十字キーで歩く。机でAを押すと盤を拭く。布団の前でAを押すと寝る
- 文（部屋に入ったとき）：
```
  全部、/自分で決めた。

  だから、/全部こぼれた。
```
- 文（机でA）：
```
  盤を拭く。

  ……傷は、/ついていない。
```
- 文（布団の前でA）：
```
  雨の音しか、/聞こえない。
```
- 次：暗転して「第5章 崩れる おわり」。第6章へ。街に「雨」の音の層が加わる
